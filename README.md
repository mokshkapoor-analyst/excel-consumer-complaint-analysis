# Consumer Complaint Analysis Dashboard

An interactive **Excel dashboard** to analyze consumer complaints filed against financial companies in the United States. This project uses real-world data to uncover complaint patterns, evaluate company response performance, and generate actionable insights for improving customer experience.

---

## 📁 Dataset Overview

This project uses a **US Consumer Complaints dataset** containing **14,000+ records** related to complaints against banks, loan providers, credit institutions, and mortgage companies. Key columns include:

- Complaint date  
- Company name  
- Product type  
- Issue category  
- Complaint channel (Email, Phone, Web, etc.)  
- Response time  
- Timely response status  
- Whether the complaint was disputed....etc

The dataset provides insights into customer behavior, common issues, and company performance in handling complaints.

---

## 🎯 Business Problem & Analysis

**Objective:** Understand how companies can reduce the number of consumer complaints and improve customer satisfaction.

**Key Analysis Goals:**

- Total complaints received and their trends over the years  
- Products generating the most issues  
- Complaint channels most used by consumers  
- Average resolution time and timely response evaluation  
- Companies receiving the highest complaints  

**Insights from Dashboard Analysis:**

- Peak complaint months identified  
- Year-over-year complaint trends observed  
- Average resolution time tracked  
- Pareto analysis shows the top 20% of issues resolving 80% of complaints  

These insights help companies focus on high-risk products, reduce resolution time, and enhance complaint handling processes.

---

## 🛠 Tools, Techniques & Concepts Used

- **Microsoft Excel**  
- Data cleaning (removing blanks, formatting dates, standardizing categories)  
- Data transformation & exploratory analysis  
- Pivot Tables & Pivot Charts  
- Calculations: averages, percentages, YoY change  
- Interactive Dashboard with slicers, charts, and KPIs  
- Pareto Analysis (80/20 rule)  
- Decision-making support via visual insights

---

## 📊 Key Insights & Findings

| Metric | Finding |
|--------|---------|
| Total complaints | 14,000+ |
| Disputed complaints | 3,138 |
| Company with highest complaints | Bank of America |
| Most common issue | Account opening, closing, or management |
| Peak complaint months | July (1,342), August (1,349) |
| Products with highest complaints | Mortgage (24%), Debt Collection (20%) |
| Main complaint channel | Web (75%), Email (12%) |
| Average resolution time | Improved from 11.7 days (2013) to 6.5 days (2016) |

**Business Insight – Pareto Analysis:**  
Focusing on the top 20% of issues can resolve nearly 80% of complaints, allowing companies to prioritize key problem areas effectively.

## 🔍 Key Learnings

- Excel can transform raw complaint data into actionable insights for businesses  
- Pivot Tables and charts are effective for summarizing and analyzing large datasets  
- Interactive dashboards with slicers allow for easy filtering and business decision support  
- Pareto Analysis is helpful for focusing on the most impactful issues  
- Year-over-Year analysis can reveal trends in complaints and resolution efficiency

---

## ⚡ Next Steps / Recommendations

- Focus on improving **account-related services** to reduce disputes  
- Optimize **web and email complaint channels** for faster resolution  
- Prioritize products like **Mortgage and Debt Collection** for process improvement  
- Regularly monitor complaint trends and resolution KPIs for continuous improvement
